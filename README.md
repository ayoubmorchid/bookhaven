# BookHaven React

A React frontend project for a bookstore-style web application. It focuses on building user-facing pages for browsing books, navigation, and shopping-style flows while connecting to a backend API during development.

This repository is presented as a frontend learning project. It is useful for showing React structure, routing, API calls, and interface work, but it should not be presented as a finished production application.

## Features

- Book browsing interface
- Page routing with React Router
- API requests with Axios
- Shopping/cart-style user flows
- Responsive page styling
- Font Awesome icons

## Tech Stack

- React
- JavaScript
- React Router
- Axios
- CSS / Tailwind workflow
- Create React App

## Local Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open:

```text
http://localhost:3000
```

The project is configured to proxy API requests to:

```text
http://127.0.0.1:8000
```
